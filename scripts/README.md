# scripts/

이 폴더는 원고 병합, 링크 점검, 코드 점검, 출판 산출물 변환을 위한 자동화 스크립트를 관리합니다.

예상 스크립트:

```text
scripts/merge_chapters.py
scripts/check_links.py
scripts/check_code_paths.py
scripts/build_manuscript.py
```

원칙:

```text
- Chapter별 원고를 publish/full_manuscript.md로 병합할 수 있어야 한다.
- 이미지 링크와 코드 경로를 점검할 수 있어야 한다.
- 최종 Word/PDF 변환 전 원고 구조를 검토할 수 있어야 한다.
```
