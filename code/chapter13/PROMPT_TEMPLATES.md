```text
- 실행 순서:

재현 SQL:
[최소 재현 SQL]

오류:
[비밀번호·접속 URL·개인정보를 제거한 오류 메시지]

기대 결과:
[행 수·오류 유형·메타데이터]

조건:
- 오류와 직접 관련 없는 파일을 수정하지 않는다.
- 기존 R1~R8 요구사항을 유지한다.
- 파괴적 SQL을 추가하지 않는다.
- 수정 전 원인과 수정 후 검증 SQL을 제시한다.
```
