# Chapter 14 RAG 검토 프롬프트 템플릿

## 1. RAG 전체 설계 검토

```text
다음 RAG 시스템 설계를 검토해 주세요.

원문 기준:
- 문서 저장소가 Source of Truth
- 문서 버전·해시·권한·활성 상태 관리
- 벡터는 재생성 가능한 파생 데이터

임베딩:
- 모델:
- 버전:
- 차원:
- 전처리:
- 청킹 전략:

검색:
- 구조화 필터:
- 키워드 검색:
- 벡터 거리:
- top_k:
- threshold:
- 정확 / HNSW / IVFFlat:

평가:
- 질문 수:
- relevance judgments:
- Precision@k·Recall@k·MRR:
- 정답 없는 질문 보류:
- 답변 근거·인용 검토:

검토 결과:
1. 원문·청크·벡터 역할 구분
2. 모델·버전·차원 호환성
3. 권한·최신성 필터 위치
4. 검색 정답표와 지표 적절성
5. 답변 근거·인용·보류 정책
6. 검색 문서 내 악성 지시 대응
7. 문서 변경·재임베딩 절차
8. 실패·복구·모니터링 계획
```

## 2. 청킹 전략 검토

```text
다음 문서 유형의 청킹 전략을 검토해 주세요.

문서 유형:
- 정책 문서 / 매뉴얼 / FAQ / 표 / 코드 / 계약서

현재 전략:
- 청크 크기:
- overlap:
- 제목·절 보존:
- 표·목록 처리:
- 출처 위치:

평가 질문:
[대표 질문과 기대 청크]

검토:
1. 조건과 예외가 분리되는 사례
2. 너무 큰 청크와 너무 작은 청크의 문제
3. 중복 검색 가능성
4. 출처 위치 복원 가능성
5. 개선 전략과 회귀 평가 기준
```

## 3. 검색 품질 평가 검토

```text
다음 벡터 검색 평가 결과를 검토해 주세요.

질문별 데이터:
- query_id
- question
- requester_scope
- top_k
- threshold
- retrieved chunks
- relevance judgments

지표:
- Precision@k
- Recall@k
- Reciprocal Rank
- MRR
- 권한 위반 검색 수
- 비활성 문서 검색 수

검토:
1. 정답 집합이 현재 검색 결과에서 독립적인가
2. 정답 없는 질문 처리가 적절한가
3. threshold 근거가 있는가
4. 중요한 개별 실패가 평균에 가려지지 않았는가
5. 평가 데이터 누수·과적합 가능성
6. 다음 회귀 평가 질문 제안
```

## 4. 답변 근거·인용 검토

```text
다음 RAG 답변을 문장별로 검토해 주세요.

질문:
[질문]

사용자 접근 범위:
[public / internal / restricted]

검색 청크:
[chunk_id, 문서 버전, 접근 범위, 본문]

생성 답변:
[답변]

검토:
1. 질문과 검색 청크의 관련성
2. 접근 권한·최신성 위반
3. 답변의 핵심 주장 목록
4. 주장별 근거 청크
5. Unsupported claim
6. 인용 누락·잘못된 인용
7. 답변 보류가 필요한지
8. 수정 답변과 보류 문구
```

## 5. 검색 문서 내 악성 지시 검토

```text
다음 검색 문서가 RAG 시스템의 신뢰 경계를 침해할 수 있는지 검토해 주세요.

문서 출처:
[출처·권한·버전]

문서 내용:
[민감정보를 제거한 내용]

시스템 권한:
- 사용 가능한 도구:
- 데이터 조회 범위:
- 데이터 변경 가능 여부:

검토:
1. 시스템·개발자 지시처럼 보이는 문장
2. 비밀정보·개인정보 출력 유도
3. 외부 URL·스크립트·숨김 텍스트
4. 도구 호출·데이터 변경 유도
5. 원문 정제·허용 출처·격리 방안
6. 답변 생성과 실행 작업 분리 방법
```

## 6. 문서·모델 변경 회귀 검토

```text

변경:
- 원문 / 청킹 / 임베딩 모델 / threshold / top_k / 인덱스 / 프롬프트

기존 기준:
- Precision@k:
- Recall@k:
- MRR:
- 보류 성공률:
- Unsupported claim:
- 권한·비활성 검색:
- 응답 시간:

새 결과:
[같은 항목]

검토:
1. 품질 개선·악화
2. 중요한 개별 질문 실패
3. 재임베딩 누락
4. 정확 검색과 근사 검색 차이
5. 운영 비용·인덱스 크기·쓰기 비용
6. 승인·조건부 승인·보류·거절 판단
```
