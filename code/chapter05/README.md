# Chapter 05 실습 코드

## 요구사항에서 데이터 모델과 ERD 만들기

이 폴더는 도서 대여 시스템의 데이터 모델을 PostgreSQL 구조와 작은 샘플 데이터로 확인하는 SQL 파일을 관리합니다.

---

## 파일 목록

| 파일 | 설명 |
| --- | --- |
| `library_schema.sql` | `members`, `books`, `loans` 테이블 생성 |
| `library_seed.sql` | 재현 가능한 명시적 ID 샘플 데이터 입력 |
| `library_validation.sql` | 행 수, NULL과 1:N 관계 연결 확인 |
| `reset_library.sql` | 필요할 때만 자식→부모 순서로 테이블 삭제 |

---

## 기본 실행 순서

1. DBeaver에서 `ai_database_book` 데이터베이스에 연결합니다.
2. SQL Editor에서 현재 데이터베이스와 스키마를 확인합니다.
3. `library_schema.sql`을 실행합니다.
4. `library_seed.sql`을 실행합니다.
5. `library_validation.sql`을 실행합니다.
6. 각 결과가 요구사항과 ERD에 맞는지 확인합니다.

```text
library_schema.sql
→ library_seed.sql
→ library_validation.sql
```

JOIN 문법과 다양한 결합 방식은 Chapter 08에서 자세히 다룹니다. Chapter 05에서는 ERD 관계가 실제 데이터로 연결되는지만 확인합니다.

외래키 오류와 참조 무결성 검증은 Chapter 06에서 진행합니다.

---

## 샘플 ID

자동 생성 ID의 이전 상태를 가정하지 않도록 실습용 ID를 명시합니다.

```text
members: 101, 102, 103
books: 201, 202, 203
loans: 1001, 1002, 1003, 1004
```

`GENERATED BY DEFAULT AS IDENTITY`는 필요할 때 명시적인 ID 입력을 허용합니다.

---

## 초기화가 필요한 경우

`library_schema.sql`과 `library_seed.sql`에는 자동 `DROP TABLE`이 없습니다.

처음부터 다시 시작해야 할 때만 다음 파일을 사용합니다.

```text
reset_library.sql
```

`reset_library.sql`은 테이블과 데이터를 모두 삭제합니다. 다음 값을 확인한 뒤 DROP 구간만 선택하여 실행합니다.

```text
current_database = ai_database_book
current_schema   = public
```

외래키 관계 때문에 자식 테이블인 `loans`를 먼저 삭제합니다.

---

## 주의 사항

```text
- 파일 전체를 무조건 반복 실행하지 않습니다.
- 같은 seed 파일을 다시 실행하면 PK 또는 UNIQUE 중복 오류가 발생할 수 있습니다.
- 실제 서비스 데이터베이스에서는 DROP TABLE을 함부로 실행하지 않습니다.
- 비밀번호나 접속 URL을 SQL 파일에 기록하지 않습니다.
- 요구사항에 없는 정책을 SQL에 임의로 추가하지 않습니다.
```
