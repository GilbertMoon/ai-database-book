# Chapter 07 프로젝트 코드

## 실전 프로젝트 1: 온라인 강의 수강신청 데이터베이스 설계

이 폴더는 Chapter 07에서 사용하는 실행 가능한 PostgreSQL 프로젝트 SQL을 관리합니다.

## 파일 목록

| 파일 | 설명 |
| --- | --- |
| `online_course_project.sql` | 테이블 생성, 샘플 데이터, JOIN, CRUD, 정규화 검토, 선택적 오류 검증을 포함한 단일 실행 파일 |

## 실행 전 주의

`online_course_project.sql`은 다음 테이블을 삭제하고 다시 생성합니다.

- `enrollments`
- `courses`
- `instructors`
- `students`

개인 실습용 `ai_database_book` 데이터베이스에서만 실행하고, 보존해야 할 데이터가 있는 데이터베이스에서는 실행하지 않습니다.

실행 전에 현재 연결 대상을 확인합니다.

```sql
SELECT current_database();
```

## 실행 순서

1. DBeaver에서 개인 실습용 PostgreSQL 데이터베이스에 연결합니다.
2. SQL Editor에서 `online_course_project.sql`을 엽니다.
3. 파일 전체를 처음부터 끝까지 실행합니다.
4. `students`, `instructors`, `courses`, `enrollments` 테이블이 생성되었는지 확인합니다.
5. 기본 샘플 입력 직후의 건수를 확인합니다.
6. JOIN 결과가 요구사항을 설명하는지 확인합니다.
7. INSERT와 UPDATE 이후 최종 상태를 확인합니다.
8. DELETE 예시는 기본 실행 흐름에서 주석 상태로 유지합니다.
9. 선택적 오류 검증 SQL은 한 문장씩 주석을 해제해 별도로 실행합니다.

## 데이터 상태 기준

| 실행 시점 | students | instructors | courses | enrollments | 비고 |
| --- | ---: | ---: | ---: | ---: | --- |
| 기본 샘플 입력 직후 | 3 | 2 | 3 | 4 | 첫 번째 JOIN 검증 기준 |
| 신규 수강신청 추가 후 | 3 | 2 | 3 | 5 | 이준호의 정규화 실습 신청 추가 |
| 상태 변경 후 | 3 | 2 | 3 | 5 | id 1 완료, id 4 취소 |
| 실제 DELETE 예시 | 변경 없음 | 변경 없음 | 변경 없음 | 실행하지 않음 | DELETE 문은 주석 상태 |

전체 SQL 파일을 끝까지 실행한 뒤에는 `enrollments`가 5행입니다. 이 최종 상태가 Chapter 08의 JOIN과 집계 실습 기준입니다.

## 기본 샘플 수강신청

기본 샘플 입력 직후의 `enrollments` 4건은 다음 관계를 검증합니다.

1. 김민지 → 데이터베이스 입문
2. 김민지 → 정규화 실습
3. 이준호 → 데이터베이스 입문
4. 박서연 → 파이썬 데이터 분석

첫 번째 전체 JOIN은 이 4건을 반환해야 합니다.

## 최종 상태

전체 SQL 파일을 끝까지 실행하면 다음 변화가 추가됩니다.

- 이준호 → 정규화 실습 수강신청이 추가됩니다.
- `enrollments.id = 1`의 상태가 `완료`로 바뀝니다.
- `enrollments.id = 4`의 상태가 `취소`로 바뀝니다.
- DELETE 예시는 주석으로 남아 있어 실제 행은 삭제되지 않습니다.

## 금액 저장 기준

이 예제는 원 단위 정수 금액만 저장한다고 가정하므로 `INT`를 사용합니다. 소수점 통화, 여러 통화, 더 큰 금액 범위가 필요하다면 `NUMERIC` 같은 타입을 검토합니다.

- `courses.price`: 강의의 현재 기본 수강료
- `enrollments.paid_amount`: 신청 시점의 실제 결제 금액

두 열은 의미와 시점이 다르므로 단순 중복으로 판단하지 않습니다.

## 주의 사항

- 운영 데이터베이스에서 실행하지 않습니다.
- 실제 개인정보, 접속 비밀번호, 내부 URL을 예제에 사용하지 않습니다.
- 파일 일부만 반복 실행하면 SERIAL ID가 달라질 수 있으므로 먼저 `SELECT` 결과를 확인합니다.
- AI가 생성한 SQL은 초안으로만 사용하고 PostgreSQL에서 직접 실행해 결과를 검증합니다.
