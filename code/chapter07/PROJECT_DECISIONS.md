## 6. 핵심 DDL 결정

```sql
CREATE UNIQUE INDEX uq_course_enrollments_active
ON course_project.enrollments (student_id, course_id)
WHERE status IN ('신청', '수강중');
```

이 인덱스는 진행 중 신청의 중복만 차단합니다. `완료`나 `취소` 이력은 여러 건 저장할 수 있습니다.

이메일 `UNIQUE`는 정확히 같은 문자열을 기준으로 합니다. 대소문자, 공백 정규화 외의 이메일 표준화와 별칭 처리는 현재 범위가 아닙니다.
