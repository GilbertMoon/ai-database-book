```text
Chapter 12. NoSQL 이해와 선택 기준
```

## 리뷰 목적

Chapter 12가 초급 학습자에게 NoSQL의 기본 개념, 관계형 데이터베이스와 NoSQL의 차이, NoSQL 유형별 특징, PostgreSQL JSONB 맛보기, 데이터 저장 방식 선택 기준, AI 추천 검토 흐름을 충분히 설명하는지 점검합니다.

또한 본문, 실습 SQL, 활동 자료, 도식, 리뷰 기록이 일관되게 연결되어 있는지 확인합니다.

## 2. NoSQL 기본 개념 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| NoSQL의 의미가 설명되었는가 | 통과 | Not Only SQL 관점으로 설명함 |
| NoSQL을 RDBMS 대체재로 오해하지 않게 설명했는가 | 통과 | 관계형 DB를 대체하는 하나의 기술이 아니라 여러 저장 방식의 계열이라고 설명함 |
| NoSQL 사용 배경이 제시되었는가 | 통과 | 캐시, 로그, 문서형 데이터, 이벤트, 관계 탐색 예시 포함 |
| 기술 우열이 아니라 선택 기준 관점인가 | 통과 | 데이터 구조, 조회 패턴, 정합성, 운영 난이도를 기준으로 판단하도록 구성됨 |

## 3. RDBMS와 NoSQL 비교 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| 관계형 DB의 강점이 설명되었는가 | 통과 | 테이블, SQL, JOIN, 트랜잭션, 정합성 중심 설명 포함 |
| NoSQL의 강점이 설명되었는가 | 통과 | 유연한 구조, 키 기반 조회, 대규모 로그, 관계 탐색 등 설명 포함 |
| 비교표가 포함되었는가 | 통과 | 기본 구조, 스키마, 질의 방식, 관계 표현, 정합성, 확장 방식, 적합 데이터 비교표 포함 |
| 거래 데이터는 RDBMS가 적합할 수 있음을 설명했는가 | 통과 | 주문, 결제, 수강신청 등 정합성 중요한 데이터 예시 포함 |
