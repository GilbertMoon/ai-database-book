# Chapter 01 출판 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 01. AI 시대에 데이터베이스를 왜 배워야 하는가
```

## 리뷰 목적

Chapter 01이 일반 독자가 혼자 읽을 수 있는 도입 장으로서 다음 역할을 수행하는지 점검한다.

```text
데이터베이스를 왜 배우는지 설명한다.
AI 시대에도 사람이 검증해야 하는 이유를 제시한다.
실행되는 SQL과 올바른 결과를 구분한다.
저장 방식 선택의 판단 기준을 제공한다.
기준 데이터·파생 데이터·AI 결과를 구분한다.
Chapter 02의 기본 개념으로 자연스럽게 연결한다.
```

## 4. 실행되는 SQL과 올바른 SQL

| 점검 항목 | 상태 | 반영 내용 |
| --- | --- | --- |
| 작은 기준 데이터 | 통과 | 학생 3명, 질문 2·1·0건 |
| `INNER JOIN` 누락 | 통과 | 질문 없는 학생 제외 |
| 1:N 중복 | 통과 | 학생 A가 두 행으로 반복 |
| 우연히 같은 숫자 | 통과 | JOIN 3행과 학생 3명의 의미 차이 |
| 네 가지 검토 질문 | 통과 | 대상·한 행·누락/중복·예상 결과 |
| 전체 학생 수 가정 | 통과 | 한 행의 의미와 상태 필터 조건 명시 |
