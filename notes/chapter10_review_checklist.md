# Chapter 10 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 10. 인덱스와 성능 기초
```

## 리뷰 목적

Chapter 10이 입문 독자에게 인덱스의 필요성, 기본 문법, 실행 계획 비교, 인덱스 설계 기준, AI 추천 인덱스 검토 흐름을 충분히 설명하는지 점검합니다.

또한 본문, 실습 SQL, 활동 자료, 도식, 리뷰 기록이 일관되게 연결되어 있는지 확인합니다.

## 4. EXPLAIN 설명 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| EXPLAIN 목적이 설명되었는가 | 통과 | SQL 실행 계획을 확인하는 도구로 설명함 |
| 인덱스 생성 전후 비교 흐름이 있는가 | 통과 | 생성 전 EXPLAIN → 인덱스 생성 → 생성 후 EXPLAIN 비교 흐름 제시 |
| Seq Scan 설명이 포함되었는가 | 통과 | 테이블을 순차적으로 확인하는 방식으로 설명 |
| Index Scan 설명이 포함되었는가 | 통과 | 인덱스를 사용해 찾는 방식으로 설명 |
| Bitmap Index Scan 설명이 포함되었는가 | 통과 | 인덱스를 활용해 여러 행을 찾는 방식으로 설명 |
| 샘플 데이터가 적을 때의 주의가 있는가 | 통과 | 데이터가 적으면 Seq Scan을 선택할 수 있다고 설명함 |
