# Chapter 07 자율 학습형 프로젝트 검수 체크리스트

## 1. 장의 역할

- [ ] Chapter 01~06의 내용을 하나의 프로젝트로 연결한다.
- [ ] 최소 완료 경로가 장 초반에 제시된다.
- [ ] 핵심·선택·심화 학습이 구분된다.
- [ ] 권장 분량이 24~27페이지 범위다.

## 2. 프로젝트 범위

- [ ] 포함 기능과 제외 기능이 분리되어 있다.
- [ ] 실제 결제·환불은 범위 밖이라고 명시한다.
- [ ] 미확정 질문을 임의로 제약조건화하지 않는다.
- [ ] 학생·강사 이메일 고유성은 각 테이블 내부 범위임을 밝힌다.

## 3. 한 행 의미와 관계

- [ ] students 한 행은 학생 한 명이다.
- [ ] instructors 한 행은 강사 한 명이다.
- [ ] courses 한 행은 개설 강의 한 개다.
- [ ] enrollments 한 행은 신청 사건 한 건이다.
- [ ] 관계를 양방향 문장으로 설명한다.
- [ ] 학생-강의 N:M 관계를 enrollments로 해소한다.

## 4. 금액 의미

- [ ] courses.price는 현재 강의 기준 가격이다.
- [ ] enrollments.recorded_amount는 신청 시 기록 금액이다.
- [ ] recorded_amount를 실제 결제 승인액이나 매출로 설명하지 않는다.
- [ ] 금액 타입은 NUMERIC(12,0)이다.
- [ ] 무료 금액 0과 NULL의 의미를 구분한다.

## 5. 상태와 이력

- [ ] CHECK는 허용 상태값만 제한한다고 설명한다.
- [ ] 상태값과 상태 전이 정책을 구분한다.
- [ ] 완료·취소 행은 이력으로 유지한다.
- [ ] 상태 변경 전 예상 이전 상태를 확인한다.
- [ ] 상태 이력은 확장 범위로 남긴다.

## 6. SQL 파일 구조

- [ ] 01 스키마 파일은 course_project 부재를 검사한다.
- [ ] 01 파일은 전체 생성을 트랜잭션으로 실행한다.
- [ ] 02 샘플 파일은 네 테이블이 비어 있는지 검사한다.
- [ ] 02 파일은 recorded_amount NUMERIC 열을 확인한다.
- [ ] 03 변경 파일은 기본 3/2/3/4 상태를 확인한다.
- [ ] 03 파일은 1001·1004 상태와 1005 부재를 검사한다.
- [ ] 03 파일은 전체 변경을 트랜잭션으로 실행한다.
- [ ] 04 검증 파일은 데이터를 변경하지 않는다.
- [ ] 04 파일은 자동 완료 조건과 통과 메시지를 제공한다.
- [ ] 05 핵심·06 선택 테스트가 분리되어 있다.

## 7. 최종 검증 기준

- [ ] students = 3
- [ ] instructors = 2
- [ ] courses = 3
- [ ] enrollments = 5
- [ ] 고아 관계 = 0
- [ ] 활성 중복 신청 = 0
- [ ] 1001 완료 / recorded_amount 100000
- [ ] 1004 취소 / recorded_amount 150000
- [ ] 1005 신청 / recorded_amount 120000
- [ ] 전체 recorded_amount = 590000
- [ ] 취소 제외 recorded_amount = 440000
