# Chapter 03 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 03. PostgreSQL과 DBeaver 실습 환경 구축
```

## 리뷰 목적

Chapter 03이 `BOOK_STYLE.md` 기준에 맞게 작성되었는지 확인하고, 초급 학습자가 PostgreSQL과 DBeaver 실습 환경을 무리 없이 구축할 수 있는지 점검합니다.

Chapter 03은 이후 SQL, ERD, 정규화, 프로젝트 실습의 기반이 되는 장이므로 다음 역할을 수행해야 합니다.

```text
- PostgreSQL과 DBeaver의 역할을 명확히 설명한다.
- 로컬 PostgreSQL과 클라우드 PostgreSQL 대안을 비교한다.
- DBeaver 연결 정보를 초급자가 이해할 수 있게 안내한다.
- 실습용 데이터베이스 생성과 기본 SQL 실행을 단계적으로 설명한다.
- setup_check.sql 실행 흐름을 본문, 코드, 활동 자료와 연결한다.
- 오류 메시지를 기록하고 ChatGPT에 질문하는 방식을 안내한다.
- 실습 SQL 파일을 GitHub 구조에 맞게 관리하도록 유도한다.
```
