## 리뷰 목적

Chapter 13이 AI가 생성한 ERD, 테이블 설계, SQL을 사람이 검토하고 수정하는 흐름을 초급 학습자에게 충분히 설명하는지 점검합니다.

또한 본문, 실습 SQL, 활동 자료, 도식, 리뷰 기록이 일관되게 연결되어 있는지 확인합니다.

## 5. SQL Anti-pattern 및 안전 검토 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| SQL Anti-pattern이 포함되었는가 | 통과 | TEXT 남용, 하나의 테이블에 모든 정보 저장, FK 누락, 상태값 제한 없음 등 포함 |
| 실행 전 안전 검토가 포함되었는가 | 통과 | 운영 DB 실행 금지, DROP/DELETE/UPDATE 확인, 백업, 권한, 개인정보 확인 포함 |
| 정보보안 관점이 포함되었는가 | 통과 | 카드번호, 비밀번호, 토큰 등 민감정보 평문 저장 위험 언급 |
| 실습 DB에서 먼저 검증하는 흐름이 있는가 | 통과 | AI SQL을 읽고 실습 DB에서 실행 후 결과 확인하도록 구성됨 |
