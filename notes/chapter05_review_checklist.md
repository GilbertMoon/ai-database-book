| 속성 설명이 적절한가 | 통과 | 엔터티가 가지는 정보로 설명하고 컬럼과 연결함 |

| 외래키 설명이 적절한가 | 통과 | 다른 테이블의 기본키를 참조해 관계를 만드는 컬럼으로 설명함 |

| JOIN 검증이 포함되어 있는가 | 통과 | ERD 설계를 조회 결과로 검증하는 흐름을 포함함 |
| 샘플 데이터와 SQL 파일이 일치하는가 | 통과 | 본문 샘플 데이터를 `library_schema.sql`의 회원 3명, 도서 3건, 대여 4건 기준으로 맞춤 |
| 단계별 산출물 표가 있는가 | 통과 | 데이터 모델링 단계별 핵심 질문과 산출물을 표로 추가함 |
| ERD와 PostgreSQL 대응표가 있는가 | 통과 | 엔터티, 속성, PK, FK, NOT NULL, UNIQUE, NULL 허용, 생성 순서를 표로 정리함 |
