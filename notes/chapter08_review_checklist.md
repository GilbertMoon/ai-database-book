## 4. 집계 설명

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| 기본 집계 | 통과 | COUNT·SUM·AVG·MIN·MAX |
| GROUP BY | 통과 | 상태별 건수·금액과 검산 |

| 금액 의미 | 통과 | 저장 금액·취소 제외·실제 매출 구분 |
| 과대 집계 | 통과 | 여러 1:N JOIN에서 반복 가능성 설명 |
