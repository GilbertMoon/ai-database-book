# notes/

이 폴더는 집필 과정에서 발생하는 작업 기록, 리뷰 기록, 점검 결과를 관리합니다.

권장 파일 예시:

```text
notes/chapter01_review.md
notes/chapter07_project_review.md
notes/full_manuscript_review.md
notes/todo.md
```

원칙:

```text
- Chapter별 수정 의견을 기록한다.
- 실습 코드 실행 검토 결과를 기록한다.
- AI가 생성한 내용 중 수정한 부분을 기록한다.
- 출판 전 전체 원고 점검 결과를 관리한다.
```
