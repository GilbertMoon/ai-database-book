# Chapter 04 최종 출판 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 04. 관계형 데이터베이스와 SQL 시작하기
```

## 리뷰 목적

Chapter 04가 SQL을 처음 배우는 독자에게 첫 테이블과 기본 CRUD를 단계적으로 제공하고, 실행 위치·예상 결과·영향 범위·실제 결과를 반복 확인하는 습관을 만들도록 구성되었는지 점검합니다.

본문뿐 아니라 단계별 SQL, 상태 확인·초기화, SVG, 이론·실습 발표자료, 의미 단위 내비게이션, 발표자 스크립트, 공통 TTS·스크립트 보강과 자동 정적 검증까지 같은 기준으로 확인합니다.

코드·문서에 구현된 상태와 PostgreSQL·브라우저·출판물에서 실제 실행·렌더링한 상태는 구분합니다.
