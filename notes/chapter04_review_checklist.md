# Chapter 04 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 04. 관계형 데이터베이스와 SQL 기초
```

## 리뷰 목적

Chapter 04가 SQL 기초 학습 장으로서 충분한 구조와 실습 흐름을 갖추었는지 점검합니다.

이 장은 Chapter 03에서 구축한 PostgreSQL과 DBeaver 환경을 바탕으로, 이후 데이터 모델링, ERD, 정규화, JOIN 학습으로 이어지는 SQL 기본기를 다지는 장입니다.

## 2. 내용 정확성 리뷰

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| SQL 분류 설명이 적절한가 | 통과 | DDL, DML, DCL, TCL을 간단히 구분함 |
| SELECT 설명이 적절한가 | 통과 | 전체 컬럼 조회와 필요한 컬럼 선택 차이를 설명함 |
| INSERT 설명이 적절한가 | 통과 | 컬럼 수와 값 수 일치, 문자열 따옴표 실수를 다룸 |

| ORDER BY 설명이 적절한가 | 통과 | ASC, DESC 차이를 설명함 |
| UPDATE 설명이 안전한가 | 통과 | WHERE 없는 UPDATE의 위험을 명확히 설명함 |
| DELETE 설명이 안전한가 | 통과 | WHERE 없는 DELETE의 위험을 명확히 설명함 |
| AI SQL 검토 기준이 있는가 | 통과 | 대상 테이블, 컬럼, 조건, 영향 범위, 실행 전 조회 기준을 제시함 |
