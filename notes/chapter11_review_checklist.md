# Chapter 11 리뷰 체크리스트

## 대상 Chapter

```text
Chapter 11. 데이터베이스 보안과 백업
```

## 리뷰 목적

Chapter 11이 초급 학습자에게 데이터베이스 보안, 계정과 권한, 최소 권한 원칙, GRANT/REVOKE, SQL Injection 방어, 백업과 복구, AI 보안·백업 명령 검토 흐름을 충분히 설명하는지 점검합니다.

또한 본문, 실습 SQL, 활동 자료, 도식, 리뷰 기록이 일관되게 연결되어 있는지 확인합니다.

## 6. 백업과 복구 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| 백업 필요성이 설명되었는가 | 통과 | 삭제, 잘못된 UPDATE, 서버 장애, 저장장치 문제, 배포 오류 예시 포함 |

| 복구 테스트 중요성이 강조되었는가 | 통과 | 백업의 완성은 복구 테스트라는 문장으로 강조함 |
| 운영 DB에서 바로 복구 테스트하지 말라고 안내하는가 | 통과 | 별도 테스트 DB에서 복구 테스트해야 한다고 설명함 |
