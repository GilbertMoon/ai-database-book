# Chapter 11 리뷰 체크리스트

## 대상 Chapter

Chapter 11. 데이터베이스 보안과 백업 기초

## 핵심 점검

| 점검 항목 | 상태 | 리뷰 의견 |
| --- | --- | --- |
| 실제 SQL 파일명이 일치하는가 | 통과 | `security_backup_check.sql`만 사용 |
| 실습 테이블명이 `security_` 기준으로 일치하는가 | 통과 | 세 개 실습 테이블 사용 |
| `UNIQUE(student_id, course_id)`를 제거했는가 | 통과 | 정책 미확정으로 추가하지 않음 |
| 인증과 권한 부여를 구분했는가 | 통과 | 표와 설명 추가 |
| PostgreSQL Role 모델을 정확히 설명했는가 | 통과 | LOGIN/NOLOGIN 구분 |
| 권한 범위를 계층별로 설명했는가 | 통과 | DB, 스키마, 테이블, 시퀀스, 역할 멤버십 |
| REVOKE 후 유효 권한 확인을 설명했는가 | 통과 | 역할 멤버십과 PUBLIC 가능성 포함 |
| Default Privileges 적용 범위를 설명했는가 | 통과 | 미래 객체와 기존 객체 구분 |
| 비밀 정보 보호와 자격 증명 회전을 설명했는가 | 통과 | `.env.example`과 노출 대응 설명 |
| SQL Injection 설명이 충분한가 | 통과 | 파라미터 바인딩과 허용 목록 구분 |
| 백업과 복제를 구분했는가 | 통과 | 목적과 주의 분리 |
| pg_dump와 전역 역할 백업 한계를 설명했는가 | 통과 | `pg_dumpall --globals-only` 언급 |
| 복구 검증 기준이 있는가 | 통과 | 3·3·3과 JOIN 3 기준 |
| SVG 접근성 구조가 있는가 | 확인 필요 | XML 검증과 렌더링 확인 필요 |
| Chapter 10/12 파일을 수정하지 않았는가 | 확인 필요 | 최종 diff에서 확인 필요 |
