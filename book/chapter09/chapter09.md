# Chapter 09. 트랜잭션과 데이터 정합성

> 상태: 초안

## 이 장에서 배울 내용

이 장에서는 여러 데이터베이스 작업을 하나의 단위로 처리하는 트랜잭션을 학습합니다.

- 트랜잭션
- ACID
- COMMIT과 ROLLBACK
- Lock과 Deadlock
- 데이터 정합성

## 왜 이 내용을 배우는가

주문, 결제, 재고 차감처럼 여러 작업이 함께 처리되어야 하는 경우가 있습니다. 일부 작업만 성공하면 데이터가 맞지 않는 문제가 생깁니다.

## 핵심 개념

### 트랜잭션

트랜잭션은 여러 DB 작업을 하나의 작업 단위로 묶어 처리하는 방법입니다.

### COMMIT과 ROLLBACK

COMMIT은 변경 내용을 확정하고, ROLLBACK은 변경 내용을 되돌립니다.

## 기본 예제

```sql
BEGIN;

UPDATE products
SET stock = stock - 1
WHERE id = 1;

INSERT INTO orders (product_id, quantity)
VALUES (1, 1);

COMMIT;
```

## 검토 질문

- 재고 차감과 주문 등록이 같은 트랜잭션 안에 있는가?
- 오류 발생 시 ROLLBACK이 가능한 구조인가?
- 동시 주문 상황에서 재고가 음수가 될 가능성은 없는가?

## 자주 하는 실수

- 여러 작업을 트랜잭션으로 묶지 않는다.
- 실패 상황을 고려하지 않는다.
- Lock과 동시성 문제를 무시한다.

## 정리

트랜잭션은 데이터 정합성을 지키기 위한 핵심 개념입니다. AI가 만든 코드도 실제 업무 흐름에서 원자성과 일관성이 유지되는지 검토해야 합니다.
