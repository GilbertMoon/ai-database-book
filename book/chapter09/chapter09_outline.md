# Chapter 09 Outline

## 제목
트랜잭션과 데이터 정합성

## 권장 분량
20~25페이지

## 이 장의 목적
여러 DB 작업을 하나의 안전한 단위로 처리하는 트랜잭션을 이해하고, 데이터 정합성을 유지하는 방법을 다룬다.

## 이 장에서 다룰 내용
- 트랜잭션의 필요성을 설명할 수 있다.
- ACID의 기본 의미를 이해할 수 있다.
- COMMIT과 ROLLBACK을 사용할 수 있다.
- Lock과 Deadlock의 개념을 이해할 수 있다.
- 주문, 결제, 재고 차감 시나리오에서 정합성 문제를 찾을 수 있다.

## 주요 개념
- 트랜잭션
- ACID
- COMMIT
- ROLLBACK
- Lock
- Deadlock
- 동시성
- 데이터 정합성
