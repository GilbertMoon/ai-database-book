# Chapter 09 Outline

## 제목

트랜잭션과 데이터 정합성

## 권장 분량

25~30페이지

## 이 장의 목적

온라인 강의 수강신청·결제·잔여 좌석 변경을 하나의 업무 단위로 처리하며, 트랜잭션 경계와 데이터 정합성 검증 방법을 이해한다.

## 이 장에서 다룰 내용

- 트랜잭션의 필요성
- `BEGIN`, `COMMIT`, `ROLLBACK`
- 데이터 정합성과 안전장치의 역할
- ACID의 기본 의미
- Chapter 09 확장 스키마
- 수강신청·결제·좌석 변경
- 실패와 `ROLLBACK`
- 동시성, Lock, Deadlock 맛보기
- AI 생성 트랜잭션 SQL 검토
