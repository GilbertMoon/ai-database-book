# Chapter 07 Outline

## 제목
중간 프로젝트 또는 중간 평가

## 권장 분량
20~25페이지

## 이 장의 목적
1~6장에서 학습한 DBMS 기본 개념, SQL 기초, ERD, 정규화를 종합하여 작은 서비스의 데이터베이스를 설계한다.

## 프로젝트 주제
온라인 강의 수강신청 시스템

## 학습 목표
- 요구사항을 읽고 테이블 후보를 도출할 수 있다.
- ERD를 작성할 수 있다.
- PostgreSQL DDL을 작성할 수 있다.
- 샘플 데이터를 입력하고 기본 SQL을 실행할 수 있다.
- AI가 생성한 설계 결과를 검토하고 수정할 수 있다.

## 주요 산출물
- 요구사항 정의서
- ERD
- CREATE TABLE SQL
- 샘플 INSERT 데이터
- 기본 SELECT 쿼리
- AI 활용 및 검토 보고서

## 평가 기준
- 요구사항 이해
- ERD 설계
- PK/FK 및 제약조건
- SQL 정확성
- 정규화 관점 검토
- AI 생성 결과 수정 내용

## 다음 장 연결
다음 장에서는 여러 테이블을 연결하여 조회하는 JOIN과 집계 쿼리를 학습한다.
