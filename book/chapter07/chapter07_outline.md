# Chapter 07 편집 구성안

## 제목

실전 프로젝트 1: 온라인 강의 수강신청 데이터베이스 설계

## 장의 역할

앞 장에서 다룬 DBMS, PostgreSQL, SQL, 데이터 모델링, ERD, 정규화 개념을 하나의 작은 서비스에 적용한다. 이 장은 점수 확인용 문제가 아니라 요구사항을 실제 데이터베이스 구조와 실행 가능한 SQL로 바꾸는 전 과정을 경험하는 실전 프로젝트 장이다.

## 핵심 질문

- 서비스 설명에서 어떤 데이터를 찾아야 하는가?
- 무엇을 테이블로 만들고 무엇을 열로 두어야 하는가?
- 학생과 강의의 N:M 관계를 어떻게 표현할 것인가?
- ERD가 실제 PostgreSQL에서 정상적으로 동작하는가?
- 샘플 데이터와 JOIN으로 설계를 어떻게 검증할 것인가?
- AI가 만든 설계에서 무엇을 사람이 직접 확인해야 하는가?

## 프로젝트 주제

온라인 강의 수강신청 시스템

## 독자가 완성할 것

- 요구사항에서 엔터티와 속성을 도출한 분석 기록
- `students`, `instructors`, `courses`, `enrollments` 중심의 ERD
- 기본키, 외래키, 제약조건을 포함한 PostgreSQL DDL
- 관계를 확인할 수 있는 샘플 데이터
- JOIN과 기본 CRUD를 사용한 검증 SQL
- 정규화와 데이터 정합성 관점의 자체 검토
- AI 제안과 최종 설계의 차이를 설명하는 기록

## 편집 원칙

- 운영, 배포, 채점, 중간고사 같은 표현은 사용하지 않는다.
- 결과물은 독자가 완성하는 프로젝트 기록이나 포트폴리오로 표현한다.
- SQL 파일은 실제 존재하는 `code/chapter07/online_course_project.sql`만 참조한다.
- 기본 ERD에는 결제 이력, 진도율, 수강평 같은 확장 테이블을 넣지 않는다.
- `courses.price`와 `enrollments.paid_amount`는 의미와 시점이 다름을 설명한다.
- DELETE는 실제 실행 흐름이 아니라 주석 처리된 선택 예시로 둔다.
- AI는 최종 판단자가 아니라 초안 작성과 검토 질문을 돕는 도구로 설명한다.
