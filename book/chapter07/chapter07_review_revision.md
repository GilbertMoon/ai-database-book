### 삽입 문안

```markdown
### 제출 전 최종 체크리스트

| 확인 항목 | 확인 질문 |
| --- | --- |
| 요구사항 분석 | 주요 명사와 엔터티 후보를 구분했는가? |
| ERD | PK, FK, 1:N, N:M 관계가 드러나는가? |
| SQL 파일 | 테이블 생성, 샘플 데이터, 조회, 수정 SQL이 포함되는가? |
| 실행 결과 | 주요 SELECT와 JOIN 결과를 기록했는가? |
| 정규화 검토 | 중복, N:M 관계, 이상 현상을 검토했는가? |
| AI 검토 | AI 답변을 그대로 쓰지 않고 수정 내용을 기록했는가? |
| 재현성 | 다른 사람이 SQL 파일을 실행해도 같은 결과를 확인할 수 있는가? |
```

### 반영 이유

Chapter 07은 중간 프로젝트 장이므로 학습자가 제출해야 할 산출물이 많습니다. 제출 전 체크리스트를 본문에 추가하면 누락을 줄이고 평가 기준과 제출물을 연결할 수 있습니다.
