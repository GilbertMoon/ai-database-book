## 10. 텍스트 ERD 작성

```text
course_project.students
- id PK
- name
- email UNIQUE
- joined_at

course_project.instructors
- id PK
- name
- email UNIQUE
- specialty

course_project.courses
- id PK
- instructor_id FK
- title
- description NULL 허용
- level
- price
- opened_at

course_project.enrollments
- id PK
- student_id FK
- course_id FK
- enrolled_at
- status
- paid_amount
- active(student_id, course_id) 부분 고유 인덱스
```

## 24. 권장 해설

```text
전용 스키마는 앞 장 객체와의 충돌을 막고 프로젝트 범위를 분명하게 한다.
무료 금액 0은 확정된 금액이고 NULL은 미확정·알 수 없음과 구분된다.
취소 신청의 paid_amount는 신청 당시 기록이며 환불은 별도 업무 사실이다.
NOT NULL은 공백 문자열을 막지 않으므로 별도 CHECK가 필요하다.
전체 이력 복합 UNIQUE는 완료·취소 후 재신청까지 차단할 수 있다.
부분 고유 인덱스는 신청·수강중 상태의 중복만 차단한다.
명시적 ID는 IDENTITY 시퀀스를 소비하지 않으므로 RESTART WITH가 필요하다.
상태 CHECK는 허용값만 제한하며 상태 전이 순서는 보장하지 않는다.
자동 커밋에서는 여러 변경 중 일부만 확정될 수 있다.
경계 테스트는 정상값을 과도하게 차단하지 않는지 확인한다.
오류 테스트는 잘못된 값과 관계가 실제로 차단되는지 확인한다.
```

오류 후 트랜잭션 종료:

```sql
ROLLBACK;
```
