## 4. 확정 요구사항과 미확정 질문

### 확정 요구사항

| 번호 | 요구사항 | 데이터·규칙 후보 |
| ---: | --- | --- |
| 1 | 학생은 이름, 이메일, 가입일을 가진다 |  |
| 2 | 강사는 이름, 이메일, 전문 분야를 가진다 |  |
| 3 | 강의는 제목, 난이도, 가격, 개설일을 가진다 |  |
| 4 | 강의는 정확히 한 강사를 참조한다 |  |
| 5 | 학생과 강의는 N:M 관계다 |  |
| 6 | 신청에는 날짜, 상태, 실제 금액을 저장한다 |  |
| 7 | 상태는 네 값 중 하나다 |  |
| 8 | 이메일은 각각 중복될 수 없다 |  |
| 9 | 금액은 음수일 수 없다 |  |
| 10 | 존재하는 부모만 참조한다 |  |

### 미확정 질문

| 질문 | 이번 처리 | 추후 확인 대상 |
| --- | --- | --- |
| 취소 후 재신청 방식 | 제한하지 않음 |  |
| 무료 강의 paid_amount | 0 사용 |  |
| 회원 탈퇴 후 이력 | 삭제 제한 |  |
| 강의 폐강 처리 | 범위 제외 |  |
| 상태 변경 이력 | 범위 제외 |  |

추가 질문:

```text

2.
3.
```

## 8. 텍스트 ERD 작성

```text
course_project.students
- id PK
- name
- email UNIQUE
- joined_at

course_project.instructors
- id PK
- name
- email UNIQUE
- specialty

course_project.courses
- id PK
- instructor_id FK
- title
- description
- level
- price
- opened_at

course_project.enrollments
- id PK
- student_id FK
- course_id FK
- enrolled_at
- status
- paid_amount
```
