# Chapter 05 Outline

## 제목
데이터 모델링과 ERD

## 권장 분량
20~25페이지

## 이 장의 목적
요구사항을 데이터 구조로 바꾸는 데이터 모델링 과정을 이해하고, ERD를 작성할 수 있도록 한다.

## 이 장에서 다룰 내용
- 엔티티, 속성, 관계를 설명할 수 있다.
- 1:1, 1:N, N:M 관계를 구분할 수 있다.
- 요구사항에서 테이블 후보를 도출할 수 있다.
- AI가 만든 ERD 초안을 검토할 수 있다.

## 주요 개념
- 데이터 모델링
- 엔티티
- 속성
- 관계
- ERD
- 1:N 관계
- N:M 관계
- 연결 테이블

## 본문 구성안
1. 데이터 모델링이란 무엇인가
2. 요구사항에서 엔티티 찾기
3. 속성과 키 정리하기
4. 관계 유형 이해하기
5. N:M 관계와 연결 테이블
6. ERD 작성 흐름
7. AI 생성 ERD 검토하기

## 실습 구성
- 도서 대여 시스템 요구사항 분석
- 엔티티와 속성 도출
- ERD 초안 작성
- ChatGPT ERD 결과 검토

## 실습 결과물
- 엔티티 목록
- ERD 초안
- AI 생성 ERD 검토표
