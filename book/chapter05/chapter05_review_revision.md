## 4. 제거한 중복 및 범위 밖 내용

```text
- SVG 내부의 전체 CREATE TABLE SQL과 전체 JOIN SQL
- SVG 내부의 대형 비교표와 전체 샘플 데이터
- 여러 그림에 반복되던 복본 관리 범위 설명
- FK ON DELETE 옵션 상세와 삭제 정책 비교
- 동시 대여 방지, 잠금, 트랜잭션 격리 수준
- 부분 인덱스와 성능 최적화
- 요구사항 추적표와 고급 정규화 검토
```

상세 설명은 본문과 Markdown 표에, 실행 내용은 SQL 코드와 SQL 파일에, 흐름과 관계는 SVG에 유지했습니다.
