# Chapter 13. ChatGPT와 Codex로 DB 설계 검증하기

> 상태: 초안

## 이 장에서 배울 내용

이 장에서는 ChatGPT와 Codex를 활용해 데이터베이스 설계와 SQL을 생성하고, 그 결과를 검증하는 방법을 학습합니다.

- ChatGPT로 요구사항 정리하기
- AI 기반 ERD 초안 생성
- Codex로 DDL과 CRUD 코드 생성
- AI 생성 SQL 검토
- SQL Anti-pattern 찾기

## 왜 이 내용을 배우는가

AI는 빠르게 초안을 만들어 주지만 항상 올바른 설계를 보장하지는 않습니다. 따라서 학습자는 AI 결과를 검토하고 수정하는 역할을 해야 합니다.

## 핵심 개념

### AI 생성 결과 검증

AI가 만든 결과를 정답으로 받아들이지 않고, 요구사항, 정규화, 키, 관계, 보안, 성능 관점에서 확인하는 과정입니다.

### SQL Anti-pattern

SQL Anti-pattern은 자주 사용되지만 장기적으로 문제를 만드는 나쁜 설계나 쿼리 패턴입니다.

## AI 활용 실습

```text
온라인 강의 수강신청 시스템의 ERD와 PostgreSQL DDL을 생성해 주세요.
학생, 강사, 강의, 수강신청, 결제 테이블을 포함해 주세요.
```

## 검토 질문

- 각 테이블에 기본키가 있는가?
- 외래키 관계가 누락되지 않았는가?
- 결제 정보와 수강신청 정보가 적절히 분리되었는가?
- 개인정보나 보안상 민감한 정보가 불필요하게 포함되지 않았는가?

## 자주 하는 실수

- AI가 만든 결과를 그대로 사용한다.
- 요구사항과 맞지 않는 테이블이 있어도 넘어간다.
- FK와 제약조건을 검토하지 않는다.
- SQL이 실행되는지만 확인하고 데이터 정합성을 검토하지 않는다.

## 정리

AI 시대의 DB 학습에서는 SQL 작성 능력과 함께 SQL 검토 능력이 중요합니다. ChatGPT와 Codex는 초안을 만드는 도구이고, 최종 판단은 사람이 해야 합니다.

3. [응용] Codex에게 CRUD 코드를 생성하게 하고 DB 연결 정보를 검토해 보세요.
