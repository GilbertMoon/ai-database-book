# Chapter 03 Outline

## 제목
PostgreSQL과 DBeaver 실습 환경 구축

## 권장 분량
20~25페이지

## 이 장의 목적
로컬 실습 환경을 PostgreSQL과 DBeaver 중심으로 통일하고, 이후 모든 실습을 진행할 수 있는 기본 환경을 준비한다.

## 학습 목표
- PostgreSQL의 역할을 이해할 수 있다.
- Postgres와 PostgreSQL이 같은 의미로 사용됨을 이해할 수 있다.
- DBeaver로 PostgreSQL에 연결할 수 있다.
- 실습용 데이터베이스를 생성할 수 있다.
- GitHub 저장소를 실습 자료 관리 공간으로 활용할 수 있다.

## 주요 개념
- PostgreSQL
- Postgres
- DBeaver
- 데이터베이스 연결
- 로컬 DB
- 클라우드 DB 대안
- GitHub 저장소

## 본문 구성안
1. 왜 PostgreSQL을 사용하는가

6. GitHub 저장소 준비
