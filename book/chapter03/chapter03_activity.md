# Chapter 03 독자 워크북

## PostgreSQL과 DBeaver로 데이터베이스 환경 만들기

> 이 워크북은 Chapter 03을 읽은 뒤 자신의 환경을 점검하고 실행 결과를 기록하기 위한 선택형 보조 자료입니다. 모든 항목을 작성할 필요는 없습니다. 설치 방식과 운영체제에 맞는 부분부터 확인해 보세요.

---

## 1. 워크북 활용 방법

이 장의 핵심은 프로그램을 설치했다는 사실이 아니라 다음 흐름이 실제로 동작하는지 확인하는 것입니다.

```text
PostgreSQL이 실행된다.
→ DBeaver에서 연결한다.
→ 작업용 데이터베이스를 선택한다.
→ SQL을 실행한다.
→ 테이블과 데이터를 확인한다.
→ 의도한 오류도 정상적으로 발생하는지 확인한다.
→ 실행 과정과 해결 방법을 기록한다.
```

비밀번호, 접속 URL, API 키는 이 워크북이나 공개 저장소에 기록하지 않습니다.

## 7. 첫 번째 테이블 만들기

```sql
CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

테이블 구조를 확인한 뒤 아래 표를 채워 봅니다.

| 열 | 데이터 타입 | 제약조건 | 역할 |
| --- | --- | --- | --- |
| id |  |  |  |
| name |  |  |  |
| email |  |  |  |
| created_at |  |  |  |

### 구조 점검

- `id`가 각 행을 구분하는 기본키인가?
- `name`은 빈 값을 허용하지 않는가?
- `email`은 중복을 허용하지 않는가?
- `created_at`에는 입력 시각이 자동으로 들어가는가?

## 16. 핵심 정리

```text
PostgreSQL은 데이터를 저장하고 SQL을 실행하는 DBMS이다.
DBeaver는 PostgreSQL에 연결해 구조와 결과를 확인하는 클라이언트 도구이다.
설치 완료보다 연결, 실행, 검증이 더 중요하다.
오류 메시지는 실패의 표시가 아니라 문제 해결을 위한 핵심 정보이다.
비밀번호와 접속 정보는 코드와 공개 저장소에서 분리해야 한다.
```
