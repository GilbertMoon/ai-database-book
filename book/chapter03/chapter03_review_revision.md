## 2. 반영 내용 A: 실습 준비 체크리스트

### 반영 위치

```text

```

### 반영 문안 요약

```text
운영체제 확인, PostgreSQL 설치 권한, 비밀번호 기록, 포트 5432, DBeaver 설치,
```

### 반영 이유

## 3. 반영 내용 B: 민감정보 보안 경고 박스

### 반영 위치

```text
Chapter 03 본문 18. 설치가 어려운 경우: 클라우드 PostgreSQL 대안
```

### 반영 문안 요약

```text
DB 비밀번호, 클라우드 DB 접속 URL, API Key, Access Token, .env 파일을 GitHub에 올리면 안 된다는 보안 주의 박스를 추가했다.
```

### 반영 이유

Chapter 03부터 GitHub와 클라우드 DB 사용이 연결됩니다. 이 단계에서 민감정보를 저장소에 올리지 않는 습관을 명확히 안내해야 이후 웹 CRUD, 배포, RAG 프로젝트에서 보안 사고를 예방할 수 있습니다.
