```markdown

| 확인 항목 | 완료 여부 |
| --- | --- |
| 내 운영체제를 확인했다. |  |
| PostgreSQL 설치 권한이 있는지 확인했다. |  |
```

## 2. 보완안 B: 민감정보 보안 경고 박스

### 삽입 권장 위치

```text
Chapter 03 본문 18. 설치가 어려운 경우: 클라우드 PostgreSQL 대안
DB 비밀번호, 접속 URL, API Key는 GitHub에 공개하지 않는다 문장 아래
```

### 삽입 문안

```markdown
> 보안 주의
>
> GitHub에 올리면 안 되는 정보는 다음과 같습니다.
>
> - DB 비밀번호
> - 클라우드 DB 접속 URL
> - API Key
> - Access Token
> - `.env` 파일
>
> 실습 파일에는 접속 정보 대신 `.env.example`처럼 예시 형식만 남기는 것이 안전합니다.
```

### 반영 이유

Chapter 03부터 GitHub와 클라우드 DB 사용이 연결됩니다. 이 단계에서 민감정보를 저장소에 올리지 않는 습관을 명확히 안내해야 이후 웹 CRUD, 배포, RAG 프로젝트에서 보안 사고를 예방할 수 있습니다.
