# Chapter 04 독자 워크북

## 관계형 데이터베이스와 SQL 시작하기

> 이 워크북은 Chapter 04를 읽은 뒤 PostgreSQL에서 첫 테이블을 만들고 기본 SQL을 실행하며, 예상 결과와 실제 결과를 비교하기 위한 선택형 보조 자료입니다.

## 1. 워크북 활용 방법

이 장의 핵심 흐름은 다음과 같습니다.

```text
현재 데이터베이스와 스키마 확인
→ students 테이블 생성
→ 샘플 데이터 입력
→ 조회·조건·정렬
→ 수정과 삭제
→ 실행 전후 검증
```

모든 SQL을 한꺼번에 실행하기보다 현재 학습 중인 구간만 선택해 실행합니다.

다음 원칙을 반복합니다.

```text
SQL 읽기
→ 예상 결과 작성
→ 실행
→ 반환 행 또는 영향받은 행 수 확인
→ 예상과 실제 비교
```
