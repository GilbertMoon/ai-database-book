- DELETE 실행 전 확인할 것

| 보완 항목 | 반영 상태 | 반영 위치 |

| 이미지 README 갱신 | 완료 | images/chapter04/README.md |
| 리뷰 체크리스트 갱신 | 완료 | notes/chapter04_review_checklist.md |

이번 추가 작업에서는 SVG가 본문 표와 SQL 코드를 반복하지 않도록 조정했습니다. 실제 SQL은 본문 코드 블록과 `basic_crud.sql`에 남기고, 그림은 조회 결과의 변화와 UPDATE/DELETE 실행 전후 확인 절차를 보여 주는 역할로 정리했습니다.

Chapter 04 입문 범위를 벗어나는 다음 내용은 이미지에서 제거했습니다.

```text
- BEGIN, COMMIT, ROLLBACK 중심의 트랜잭션 흐름
- SELECT ... FOR UPDATE
- FK 삭제 정책과 ON DELETE 옵션
- 소프트 삭제 설계
- 실행 계획, 권한 관리, 운영 데이터 삭제 절차
```

Word/PDF/eBook 변환은 실제 제작 도구에서 수행하지 않았습니다. 대신 SVG XML 검증과 브라우저 렌더링 캡처로 한글, 화살표, 박스 배치를 확인했습니다. 최종 출판 변환 단계에서는 SVG 또는 PNG 변환 결과를 다시 확인해야 합니다.
