# Chapter 04 Outline

## 제목
관계형 데이터베이스와 SQL 기초

## 권장 분량
20~25페이지

## 이 장의 목적
관계형 데이터베이스의 기본 구조를 이해하고, PostgreSQL에서 기본 CRUD SQL을 실행할 수 있도록 한다.

## 이 장에서 다룰 내용
- 관계형 데이터베이스의 기본 구조를 설명할 수 있다.
- SELECT, INSERT, UPDATE, DELETE를 작성할 수 있다.
- WHERE, ORDER BY를 활용해 데이터를 조회할 수 있다.
- AI가 생성한 기본 SQL의 오류를 검토할 수 있다.

## 주요 개념
- RDBMS
- SQL
- SELECT
- INSERT
- UPDATE
- DELETE
- WHERE
- ORDER BY
- CRUD

## 본문 구성안
1. 관계형 데이터베이스란 무엇인가
2. SQL의 역할
3. SELECT로 데이터 조회하기
4. INSERT로 데이터 추가하기
5. UPDATE로 데이터 수정하기
6. DELETE로 데이터 삭제하기
7. WHERE와 ORDER BY
8. AI가 만든 SQL 검토하기
