# book/

이 폴더는 Chapter별 원고와 구성안을 관리합니다.

현재 구조:

```text
book/
├── chapter01/
│   ├── chapter01_outline.md
│   └── chapter01.md
├── chapter02/
│   ├── chapter02_outline.md
│   └── chapter02.md
└── ...
```

원칙:

```text
- `chapterXX_outline.md`에는 장별 구성, 학습 목표, 실습 계획을 작성한다.
- `chapterXX.md`에는 실제 eBook 원고를 작성한다.
- 각 Chapter는 하나의 수업 단위로 완결성을 갖도록 작성한다.
- 원고, 실습 코드, 도식, 리뷰 기록은 함께 관리한다.
```
