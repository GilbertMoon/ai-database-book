# Chapter 06 Outline

## 제목
정규화와 좋은 테이블 설계

## 권장 분량
20~25페이지

## 이 장의 목적
중복 데이터와 이상 현상을 이해하고, 1NF~3NF 수준의 기본 정규화를 실습한다.

## 이 장에서 다룰 내용
- 데이터 중복이 만드는 문제를 설명할 수 있다.
- 삽입, 수정, 삭제 이상을 이해할 수 있다.
- 1NF, 2NF, 3NF의 기본 의미를 설명할 수 있다.
- AI가 만든 나쁜 테이블 구조를 개선할 수 있다.

## 주요 개념
- 정규화
- 중복 데이터
- 이상 현상
- 1NF
- 2NF
- 3NF
- 반정규화

## 본문 구성안
1. 좋은 테이블 설계란 무엇인가
2. 데이터 중복의 문제
3. 삽입/수정/삭제 이상
4. 1NF 이해하기
5. 2NF 이해하기
6. 3NF 이해하기
7. 반정규화가 필요한 경우
8. AI 생성 테이블 정규화 검토

## 실습 구성
- 하나의 큰 테이블을 여러 테이블로 분리하기
- 중복 컬럼 찾기
- 정규화 전후 구조 비교하기

## 실습 결과물
- 정규화 전 테이블
- 정규화 후 테이블 구조
- 설계 개선 보고서
