# Chapter 06. 정규화와 좋은 테이블 설계

> 상태: 초안

## 이 장에서 배울 내용

이 장에서는 데이터 중복을 줄이고 좋은 테이블 구조를 만드는 정규화를 학습합니다.

- 데이터 중복 문제
- 삽입, 수정, 삭제 이상
- 1NF, 2NF, 3NF
- 나쁜 설계와 좋은 설계 비교
- AI 생성 테이블 구조 검토

## 왜 이 내용을 배우는가

처음에는 하나의 큰 테이블에 모든 정보를 넣는 방식이 쉬워 보입니다. 하지만 데이터가 늘어나면 중복과 오류가 생깁니다.

## 핵심 개념

### 정규화

정규화는 데이터 중복을 줄이고 테이블 구조를 안정적으로 만드는 설계 방법입니다.

### 이상 현상

잘못 설계된 테이블에서는 데이터를 추가, 수정, 삭제할 때 예기치 않은 문제가 생길 수 있습니다.

## AI 활용 실습

```text
학생, 강의, 강사, 수강신청 정보를 하나의 테이블로 만든 예시를 작성하고,
이 구조를 정규화하여 여러 테이블로 분리해 주세요.
```

## 검토 질문

- 같은 데이터가 여러 행에 반복되는가?
- 특정 정보만 수정하기 어려운 구조인가?
- 테이블을 분리했을 때 관계가 명확해졌는가?

## 자주 하는 실수

- 모든 테이블을 무조건 많이 나누려고 한다.
- 중복을 줄이면서도 관계를 잃어버린다.
- 성능을 이유로 너무 일찍 반정규화를 적용한다.

## 정리

정규화는 좋은 데이터베이스 설계의 기본입니다. 초급 단계에서는 1NF~3NF의 개념과 중복 제거 이유를 이해하는 것이 중요합니다.

## 연습 문제

1. [기초] 정규화가 필요한 이유를 설명해 보세요.
2. [기초] 데이터 중복의 문제를 예로 들어 보세요.
3. [응용] 하나의 주문 테이블을 회원, 주문, 상품 테이블로 나누어 보세요.
4. [심화] AI가 만든 테이블 구조에서 정규화 문제를 찾아 수정해 보세요.
