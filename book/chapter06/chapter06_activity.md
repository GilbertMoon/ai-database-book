# Chapter 06 독자 워크북

## 정규화와 데이터 무결성으로 좋은 테이블 만들기

> 이 워크북은 Chapter 06을 읽은 뒤 중복과 이상 현상을 분석하고, 정규화된 구조와 무결성 제약조건이 실제로 잘못된 데이터를 차단하는지 확인하기 위한 선택형 보조 자료입니다.

---

## 1. 워크북 활용 방법

이 장의 핵심 흐름은 다음과 같습니다.

```text
한 행의 의미 확인
→ 컬럼의 주인 찾기
→ 이상 현상 분석
→ 1NF·2NF·3NF 이해
→ 정규화 구조 작성
→ 무결성 제약조건 적용
→ 정상·오류 데이터 테스트
→ AI 설계 검토
```

사용 파일:

```text
code/chapter06/normalization_schema.sql
code/chapter06/normalization_seed.sql
code/chapter06/normalization_practice.sql
code/chapter06/integrity_tests.sql
code/chapter06/reset_normalization.sql
```

Chapter 05 테이블과 충돌하지 않도록 다음 실습 전용 이름을 사용합니다.

```text
library_records_raw
members_nf
books_nf
loans_nf
```
