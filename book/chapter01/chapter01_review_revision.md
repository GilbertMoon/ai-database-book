## 3. 새로 추가한 내용

### 3.1 실행 성공과 결과 정확성의 차이

질문이 없는 학생까지 포함해야 하는 집계에 `INNER JOIN`을 사용한 사례를 추가했습니다.

검토 항목은 다음과 같습니다.

```text
기준 테이블
JOIN으로 누락되는 대상
JOIN으로 중복되는 행
COUNT가 실제로 세는 대상
원본 데이터와 예상 결과
```

### 3.2 데이터 오류의 파급 과정

```text
중복·누락·잘못된 관계
→ 잘못된 SQL 결과
→ 잘못된 AI 분석
→ 잘못된 의사결정
```

중복 주문, 누락된 고객, 취소 주문 포함, 오래된 상태, NULL 오해 사례를 추가했습니다.

### 3.3 역할별 DB 필요성

개발자뿐 아니라 기획자, 운영자, 분석가, 마케터와 관리자도 데이터 관계와 집계 결과를 이해해야 하는 이유를 표로 정리했습니다.

### 3.4 DB를 배워야 하는 다섯 가지 근본 이유

```text
1. AI가 만든 결과를 검증하기 위해
2. 현실의 업무를 데이터 구조로 표현하기 위해
3. 정확한 데이터로 분석하고 의사결정하기 위해
4. AI 기능을 운영 가능한 서비스로 만들기 위해
5. 데이터의 안전성·이력·복구 가능성을 확보하기 위해
```

### 3.5 원본 데이터와 파생 데이터

회원·주문·결제·출석·문서 원문은 기준 데이터로, 집계·대시보드·캐시·AI 요약과 분류 결과는 파생 데이터로 설명했습니다.
