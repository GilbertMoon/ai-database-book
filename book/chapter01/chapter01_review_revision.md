## 1. 대상 독자와 선수 지식 명시

## 2. 완료 기준 추가

장 전체 내용을 읽은 뒤 다음 내용을 설명할 수 있도록 완료 기준을 제시했다.


## 3. 핵심·선택·심화 표시 도입(개편 당시)

개편 당시에는 책 전체에서 사용할 세 가지 학습 표시를 Chapter 01에서 안내했다. 최종 출판본에서는 이 역할을 Overview로 이동했다.

```text

```

선택·심화 내용을 모두 완료하지 않아도 다음 장으로 진행할 수 있음을 명시했다.

## 4. 본문 구조 17절에서 15절로 정리(개편 당시)

기존의 다음 두 절을 별도로 유지하지 않고 관련 내용에 통합했다.

```text
‘운영되는 AI 서비스도 데이터를 관리해야 한다’
→ 데이터베이스를 배우는 이유에 통합

‘비전공자도 데이터베이스를 알아야 하는 이유’
→ 현실의 업무와 역할별 활용에 통합
```

개편 당시 본문은 다음 15개 절로 구성했다.

```text
1. AI가 SQL을 만들어 주는데도 DB를 배워야 할까
2. 데이터베이스를 배워야 하는 다섯 가지 이유
3. 실행되는 SQL과 올바른 SQL은 다르다
4. AI가 만든 테이블도 구조적으로 틀릴 수 있다
5. 잘못된 데이터가 잘못된 결과를 만든다
6. 현실의 업무를 데이터와 관계로 표현하기
7. 파일·스프레드시트·DBMS 중 무엇을 선택할까
8. 기준 데이터·파생 데이터·AI 결과 구분하기
9. AI가 잘하는 일과 사람이 확인할 일
10. 이 책을 학습하는 방법
11. 직접 판단해 보기
12. 자주 하는 오해
13. 스스로 확인하기
14. 핵심 정리
15. 다음 장에서는
```

## 5. AI SQL 검토 기준 압축

상세 검토 항목을 초보자가 기억하기 쉬운 네 질문으로 정리했다.

```text
무엇을 세거나 조회하려는가?
결과의 한 행은 무엇을 의미하는가?
누락되거나 중복되는 데이터는 없는가?
작은 예제의 예상 결과와 일치하는가?
```

기존 학생 3명과 질문 수 `2 / 1 / 0` 사례는 유지했다.

## 6. 고급 운영 내용 이동

Chapter 01에서는 다음 상세 목록을 제거하거나 선택 학습으로 축소했다.

```text
모델 식별자와 버전
프롬프트 템플릿 버전

```

Chapter 01에서는 중요한 AI 결과가 어떤 데이터와 지시를 사용했는지 확인할 수 있어야 한다는 원칙만 유지한다. 상세 검증과 기록은 Chapter 13으로 이동한다.

## 7. 금액 용어 단순화

기존 결제·환불·순금액·회계 매출의 상세 구분을 도입 장에서 축소했다.

```text

```

상세 구조와 상태는 Chapter 07·09·13에서 다룬다.

## 8. 기준·파생·AI 결과 설명 단순화

세 종류의 구분은 유지하되 운영 수준의 재현 조건과 보존 정책은 제거했다.

```text
기준 데이터
→ 특정 업무 판단에서 공식 기준으로 삼는 데이터

파생 데이터
→ 기준 데이터를 계산해 만든 결과

AI 생성 결과
→ 모델·입력 데이터·지시에 따라 달라질 수 있는 결과
```

## 9. 자율 학습 흐름 강화(개편 당시)

개편 당시 ‘이 책에서 배우는 흐름’을 ‘이 책을 학습하는 방법’으로 바꾸고 다음 순서를 제시했다. 최종 출판본에서는 Overview가 동일한 역할을 충분히 담당하므로 이 절을 Chapter 01 본문에서 제거했다.

```text
핵심 개념 읽기
→ 작은 예제의 결과 예상
→ 직접 실행
→ 실제 결과 확인
→ AI 초안 검토
→ 오류 수정
→ 자신의 말로 정리
```

특정 일정, 평가, 제출과 연결되는 표현은 사용하지 않았다.

## 10. 독자 워크북 재구성

워크북 활동을 다음처럼 구분했다.

```text
핵심 활동
- DB를 배우는 이유
- 저장 방식 비교
- 잘못된 SQL 검토
- 데이터 오류의 파급 추적

선택 활동
- 사례별 저장 방식
- 기준·파생·AI 결과 구분
- ChatGPT 추천 검토
- 역할과 자신의 서비스 적용

심화 활동
- 중요한 AI 결과의 최소 기록 항목
```

기존 AI 실행 맥락 활동은 항목 수를 줄이고 개인정보와 비밀정보 주의를 강화했다.

## 11. 유지한 핵심 자산

다음 핵심 내용과 도식은 유지했다.

```text
실행 성공과 결과 정확성의 차이
학생 3명과 질문 2·1·0건 사례
잘못된 단일 수강신청 테이블
파일·스프레드시트·DBMS 비교
기준 데이터·파생 데이터·AI 결과
AI 생성 결과 검증 사이클
책 전체 학습 흐름 도식은 파일로 보관하되 최종 Chapter 01 본문에서는 Overview와 중복되어 제외
```

최종 Chapter 01 본문에서는 저장 방식 선택과 AI 결과 검증 도식 두 개를 사용한다.

## 13. 최종 출판 검수 반영

PDF/eBook 제작 전 최종 검수에서 다음 내용을 추가로 정리했다.

```text
Overview 중복
→ ‘이 책을 학습하는 방법’ 절 제거
→ 15개 절에서 14개 절로 재정렬

AI 표현
→ 특정 속도와 능력을 단정하는 문장을 역할 중심 표현으로 수정

초보자 범위
→ JOIN과 IDENTITY는 지금 암기하지 않아도 된다는 안내 추가

데이터 품질 표
→ PDF 가독성을 위해 4열을 3열로 단순화

관계 화살표
→ 외래키 방향이 아니라 개념적 연결임을 명확화

Source of Truth
→ 특정 업무 판단에서 공식 기준으로 삼는 데이터로 정의
→ 가장 먼저 만들어진 파일과 동일한 개념이 아님을 안내

출판 Markdown
→ 표 안 HTML img와 br 제거
→ 독자 워크북 경로를 Markdown 링크로 변경

도식
→ 책 전체 학습 흐름 도식은 Overview와 중복되어 Chapter 01 본문에서 제외
→ 본문 도식은 그림 1-1과 그림 1-2 두 개로 정리
```

현재 Chapter 01은 ‘왜 데이터베이스를 배워야 하는가’와 ‘AI 결과를 무엇으로 검증해야 하는가’에 집중하고, 책 전체 학습 안내는 Overview에 맡긴다.
