## 7. AI가 만든 SQL 결과 검토하기

다음 질문에 대한 SQL을 AI가 작성했다고 가정합니다.

```text
질문을 한 번도 작성하지 않은 학생까지 포함한 전체 학생 수를 계산해 주세요.
```

AI가 다음 SQL을 제안했습니다.

```sql
SELECT COUNT(*) AS student_count
FROM students s
INNER JOIN questions q
    ON q.student_id = s.id;
```

다음 표를 작성해 보세요.

| 검토 항목 | 나의 판단 |
| --- | --- |
| SQL은 문법적으로 실행될 수 있는가? |  |
| 어떤 학생이 결과에서 제외되는가? |  |
| 한 학생이 질문을 여러 개 작성하면 어떤 문제가 생기는가? |  |
| `COUNT(*)`는 무엇을 세는가? |  |
| 확인해야 할 원본 행은 무엇인가? |  |
| 더 적절한 접근 방법은 무엇인가? |  |

### AI 생성 SQL 검토 순서

```text
1. 질문과 요구사항을 다시 읽는다.
2. 기준이 되는 테이블을 확인한다.
3. JOIN으로 누락되거나 중복되는 행을 확인한다.
4. 필터, NULL과 집계 기준을 확인한다.
5. 실행 전에 예상 결과를 적는다.
6. 실제 결과와 원본 데이터를 비교한다.
```
