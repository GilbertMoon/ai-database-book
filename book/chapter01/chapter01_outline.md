# Chapter 01 구성안

## 제목

AI 시대에 데이터베이스를 왜 배우는가

## 권장 분량

15~20페이지

## 이 장의 역할

일반 독자가 데이터베이스를 단순한 SQL 문법이 아니라, 데이터를 구조화하고 서비스의 규칙을 관리하는 기술로 이해하도록 안내한다. ChatGPT와 Codex가 SQL과 코드를 생성하는 시대에도 사람이 데이터 구조, 업무 규칙, 정합성, 보안과 확장성을 판단해야 하는 이유를 설명한다.

## 독자가 얻게 될 것

- 데이터, 파일, 엑셀, 데이터베이스의 차이를 설명할 수 있다.
- 데이터베이스가 필요한 상황과 필요하지 않은 상황을 구분할 수 있다.
- AI가 생성한 데이터 모델과 SQL을 검토해야 하는 이유를 이해할 수 있다.
- ChatGPT, Codex, PostgreSQL, DBeaver, GitHub를 연결한 작업 흐름을 파악할 수 있다.
- 이 책의 전체 구성과 실전 프로젝트의 방향을 이해할 수 있다.

## 주요 개념

- 데이터
- 데이터베이스
- DBMS
- 파일 기반 저장
- 엑셀과 데이터베이스의 차이
- 데이터 관계와 정합성
- AI 생성 결과 검증
- AI 보조 개발

## 독자 참여 요소

- 사례별로 파일, 엑셀, 관계형 DB 중 적절한 저장 방식 판단하기
- ChatGPT에 저장 방식을 질문하고 답변의 근거와 누락 사항 검토하기
- 잘못된 AI 답변에서 확장성, 관계, 정합성, 보안 문제 찾기
- 자신이 만들고 싶은 서비스의 저장 구조를 한 페이지로 정리하기

## AI 활용 포인트

- ChatGPT로 서비스 요구사항과 데이터 후보를 정리한다.
- AI가 추천한 저장 방식이 현재 규모와 확장 가능성에 모두 맞는지 검토한다.
- AI가 생성한 SQL을 정답이 아닌 초안으로 다룬다.
- 사람이 확인해야 할 질문을 구체적으로 제시한다.

## 독자가 직접 정리할 내용

- 데이터베이스 필요 여부 판단표
- 자신이 만들고 싶은 서비스의 데이터 목록
- 추천 저장 방식과 선택 근거
- AI 답변에서 타당한 부분과 수정한 부분
