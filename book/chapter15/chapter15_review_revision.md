# Chapter 15 리뷰 반영 기록

## 대상

Chapter 15. 실전 프로젝트 2: AI 기반 데이터베이스 서비스 완성하기

## 반영 요약

Chapter 15를 책 전체의 최종 통합 프로젝트 장으로 재구성했습니다. 기본 목표는 AI 기능을 많이 넣는 것이 아니라, 필수 데이터베이스 설계와 실행 검증 근거를 완성하는 것입니다.

## 변경 이력

| 영역 | 반영 내용 |
|---|---|
| 본문 | 필수 DB 완성과 선택 확장을 분리하는 흐름으로 재작성 |
| AI 의미 | AI는 기본적으로 설계·SQL 검토 보조 도구로 설명, RAG는 선택 확장으로 정리 |
| CRUD | 필수 단계가 아니라 선택 확장으로 수정 |
| 파일명 | 이전 임시 파일명 표현을 제거하고 `ai_review_report.md`, `final_report.md`로 통일 |
| 코드 README | `code/chapter15/README.md` 생성 |
| 템플릿 README | 복사해 프로젝트 README로 사용할 수 있는 구조로 재작성 |
| 요구사항 | REQ-01~REQ-10과 DB 반영/검증 방법 추가 |
| 미확정 규칙 | 제약 조건으로 고정하지 않을 항목을 분리 |
| DDL | AI 튜터링 질문 관리 서비스 기준으로 재작성 |
| seed | 고정 PK 의존을 제거하고 검증 시나리오 데이터 구성 |
| queries | JOIN, 집계, N:M, LEFT JOIN, 정합성, FK, 트랜잭션 검증 추가 |
| 인덱스 | 실제 조회 패턴 기반 후보로만 설명 |
| 보안 | 개인정보, 비밀번호, 백업·복구, 운영 DB 주의 추가 |
| 그림 | 8개 Mermaid와 8개 SVG를 본문 순서에 맞게 단순화 |
| 리뷰 문서 | 실제 반영 결과와 미확인 항목 기준으로 갱신 |
