# Chapter 15. 최종 프로젝트 또는 최종 평가

> 상태: 초안

## 이 장에서 수행할 프로젝트

이번 장에서는 책 전체에서 배운 내용을 종합하여 실행 가능한 미니 서비스를 설계하고 구현합니다.

## 프로젝트 목표

최종 프로젝트의 목표는 단순히 테이블을 만드는 것이 아니라, 데이터베이스 설계 결과를 실제 웹 형태로 확인하는 것입니다.

```text
요구사항 정의
→ ERD 작성
→ PostgreSQL DDL 작성
→ 샘플 데이터 입력
→ 핵심 SQL 작성
→ Codex로 웹 CRUD 구현
→ GitHub 관리
→ AI 활용 및 검증 보고서 작성
```

## 프로젝트 주제 후보

1. AI 튜터링 서비스
2. RAG 기반 문서 검색 시스템
3. 온라인 강의 플랫폼
4. 쇼핑몰 주문/결제/재고 시스템
5. 병원 예약 시스템

## 필수 산출물

```text
- 요구사항 정의서
- ERD
- DDL
- 샘플 데이터
- 핵심 SQL
- 간단한 웹 CRUD 화면
- GitHub 저장소
- AI 활용 보고서
- 검증 보고서
```

## AI 활용 실습

```text
AI 튜터링 서비스를 위한 데이터베이스 설계와 웹 CRUD 구현 계획을 작성해 주세요.
학생, 튜터, 질문, 답변, 학습 자료 테이블을 포함해 주세요.
```

## 검토 질문

- 요구사항이 테이블 구조에 반영되었는가?
- PK, FK, 제약조건이 적절한가?
- 웹 CRUD가 실제 DB와 연결되어 동작하는가?
- AI가 생성한 설계와 코드를 사람이 검토했는가?
- 보안, 정규화, 성능 관점의 검토가 포함되었는가?

## 평가 기준

| 항목 | 비율 |
| --- | ---: |
| 요구사항 분석 | 15% |
| DB 설계 | 25% |
| SQL 작성 | 20% |
| 웹 CRUD 구현 | 20% |
| AI 활용 및 검증 보고서 | 20% |

## 최종 정리

이 책의 목표는 AI가 만들어 주는 결과를 그대로 사용하는 것이 아니라, 데이터베이스의 기본 원리를 바탕으로 AI 결과를 검증하고 실행 가능한 서비스로 연결하는 것입니다.
