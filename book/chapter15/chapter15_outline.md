# Chapter 15 Outline

## 제목
최종 프로젝트 또는 최종 평가

## 권장 분량
35~45페이지

## 이 장의 목적
전체 교재에서 학습한 DB 개념, SQL, 설계, 트랜잭션, 인덱스, 보안, NoSQL, AI 검증, Vector DB/RAG 개념을 종합하여 실행 가능한 미니 서비스를 완성한다.

## 프로젝트 주제 후보
- AI 튜터링 서비스 DB 설계 및 웹 CRUD
- RAG 기반 문서 검색 시스템
- 온라인 강의 플랫폼 확장 프로젝트
- 쇼핑몰 주문/결제/재고 관리 시스템

## 학습 목표
- 요구사항 정의서를 작성할 수 있다.
- ERD와 DDL을 작성할 수 있다.
- 샘플 데이터와 핵심 SQL을 작성할 수 있다.
- Codex를 활용해 간단한 웹 CRUD를 구현할 수 있다.
- AI 활용 보고서와 검증 보고서를 작성할 수 있다.

## 주요 산출물
- 요구사항 정의서
- ERD
- DDL
- 샘플 데이터
- 핵심 SQL
- 웹 CRUD 화면
- GitHub 저장소
- AI 활용 보고서
- 검증 보고서

## 평가 기준
- 요구사항 분석
- DB 설계 품질
- SQL 정확성
- 웹 구동 여부
- AI 생성 결과 검토
- 보안/정규화/성능 검토
- 문서화 품질
