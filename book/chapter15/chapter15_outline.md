# Chapter 15. 실전 프로젝트 2: AI 기반 데이터베이스 서비스 완성하기

## 장의 목표

책 전체의 데이터베이스 개념을 하나의 통합 프로젝트로 연결하고, 필수 DB 설계와 선택 확장을 구분해 재현 가능한 결과물을 완성한다.

## 핵심 개념

- 필수 범위
- 제외 범위
- 선택 확장
- 요구사항 ID
- 미확정 업무 규칙
- 요구사항 추적
- 검증 시나리오 데이터
- 정상/경계/오류 테스트
- 예상 결과와 실제 결과
- 트랜잭션 검증
- 인덱스 후보
- 보안과 개인정보
- 백업과 복구
- AI diff 검토
- 완성 판단 게이트
- 원본 문서와 실행 근거

## 본문 구성

1. 완성형 데이터베이스 프로젝트란 무엇인가
2. 필수 범위와 선택 확장을 구분한다
3. 재현 가능한 프로젝트 구조를 먼저 준비한다
4. 프로젝트 주제를 선택한다
5. 요구사항과 미확정 업무 규칙을 작성한다
6. ERD와 DDL이 일치하는지 확인한다
7. 검증 시나리오 데이터를 설계한다
8. 필수 SQL과 검증 쿼리로 요구사항을 증명한다
9. 데이터 변경과 트랜잭션을 검토한다
10. 실제 조회 패턴과 인덱스를 검토한다
11. 보안, 개인정보, 백업과 복구를 검토한다
12. AI 초안을 검토하고 사람의 수정 근거를 남긴다
13. 통합 DB가 완성됐는지 판단한다
14. 필요한 선택 확장을 판단한다
15. 설계 결정과 검증 근거를 문서화한다
16. 최종 완료 여부를 점검한다
17. 자주 하는 실수
18. 책 전체의 개념을 다시 연결한다
19. 프로젝트 회고와 다음 버전
20. 이후 학습 방향
