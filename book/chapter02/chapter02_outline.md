Chapter 01의 핵심 내용을 읽었다면 별도의 선수 지식은 필요하지 않다. Chapter 02의 SQL과 테이블은 구조와 용어를 이해하기 위한 축약 예제로 사용한다. 실제 PostgreSQL 환경은 Chapter 03에서 준비하고 첫 테이블과 기본 SQL은 Chapter 04에서 다룬다.

## 이 장의 역할

Chapter 02는 새로운 개념을 많이 소개하는 장이 아니라 다음 구조를 정확한 용어로 읽는 장이다.

```text
사용자
```

Chapter 01의 학습 동기와 판단 기준을 이어받되, Chapter 02에서는 기본 용어와 구조 읽기를 담당한다.


## PostgreSQL 기준 안내

이 책의 계층과 용어는 PostgreSQL을 기준으로 설명한다. 다른 DBMS에서는 데이터베이스와 스키마의 사용 방식 또는 명칭이 다를 수 있음을 짧게 안내한다. 이 책에서 “PostgreSQL 서버”는 PostgreSQL DBMS가 실행되는 하나의 인스턴스를 이해하기 쉽게 부르는 표현이며 로컬 PC와 원격 환경 모두에 적용한다. 제품별 비교를 Chapter 02에서 상세하게 다루지 않는다.

## 핵심 구조 설명

### 클라이언트와 DBMS

```text
사용자
→ DBeaver, psql, Python, 웹 애플리케이션과 같은 클라이언트
→ PostgreSQL DBMS
```

DBeaver는 여러 클라이언트 도구 중 하나이며 DBMS 자체가 아님을 명확히 한다.

### PostgreSQL 계층

```text
PostgreSQL 서버
└── 데이터베이스
    └── 스키마
        └── 데이터베이스 객체
            ├── 테이블
            ├── 뷰
            ├── 시퀀스
            └── 함수
```

Chapter 02에서는 테이블만 자세히 다룬다. Chapter 08에서는 JOIN과 집계로 조회 결과를 만드는 방법을 확장하고, 분석용 VIEW의 생성과 활용은 Chapter 14에서 다룬다.

### 테이블과 조회 결과

```text
테이블
→ 데이터를 저장하는 구조

조회 결과
→ SELECT의 조건·연결·계산에 따라 만들어진 결과 집합
```

화면에서 모두 표처럼 보여도 같은 개념이 아님을 설명한다.

### 식별자

```text
내부 식별자
→ DB 내부에서 행을 안정적으로 구분

업무 식별자
→ 학번, 회원번호, 주문번호처럼 업무에서 사용
```

자연키와 대체키의 상세 설계는 Chapter 05~06으로 넘긴다.

### 기본키와 외래키

```text
기본키
→ 자신의 테이블에서 행을 고유하게 구분

외래키
→ 참조 대상 키와 연결되어 업무 관계를 표현

외래키 제약조건
→ 존재하지 않는 참조가 저장되지 않도록 검사
```

외래키 값은 반복될 수 있고 자동으로 `UNIQUE` 또는 `NOT NULL`이 되지 않는다는 경계를 유지한다.

## 데이터 타입 선택 기준

구체적인 PostgreSQL 타입 문법은 Chapter 04로 넘기고 다음 질문만 제시한다.

```text
이 값은 계산하는 값인가?
앞자리 0을 보존해야 하는가?
날짜나 시각 연산이 필요한가?
값의 허용 범위가 정해져 있는가?
```

데이터 타입은 값의 큰 범위를 정하고, 더 구체적인 업무 규칙은 Chapter 06의 제약조건으로 보완한다.
