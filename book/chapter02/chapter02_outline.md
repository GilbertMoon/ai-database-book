# Chapter 02 Outline

## 제목
DBMS 기본 개념

## 권장 분량
15~20페이지

## 이 장의 목적
데이터베이스를 처음 배우는 학습자가 DBMS의 핵심 구성 요소와 용어를 이해하도록 한다.

## 학습 목표
- 데이터베이스와 DBMS의 차이를 설명할 수 있다.
- 테이블, 행, 열의 의미를 설명할 수 있다.
- 기본키(PK)와 외래키(FK)의 역할을 이해할 수 있다.
- 관계, SQL, CRUD, 제약조건의 기본 의미를 이해할 수 있다.

## 주요 개념
- 데이터베이스
- DBMS
- 테이블
- 행(Row)
- 열(Column)
- 기본키(PK)
- 외래키(FK)
- 관계
- SQL
- CRUD
- 제약조건

## 본문 구성안
1. DBMS란 무엇인가
2. 테이블, 행, 열 이해하기
3. 기본키와 외래키
4. 테이블 간 관계
5. SQL과 CRUD
6. 제약조건이 필요한 이유
7. AI가 만든 테이블 구조 검토하기

## 실습/활동
- 학생 테이블과 수강신청 테이블 구조 그려 보기
- PK와 FK 후보 찾기
- ChatGPT가 만든 테이블 구조에서 문제 찾기

## AI 활용 포인트
- ChatGPT에게 학생 관리 시스템 테이블 구조를 생성하게 한다.
- 생성된 테이블에서 PK, FK, 중복 컬럼, 누락된 관계를 검토한다.

## 산출물
- DBMS 기본 용어 정리표
- 학생-수강신청 예제 테이블 구조
