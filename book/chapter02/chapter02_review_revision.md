## 4. 새로 추가하거나 강화한 내용

### 4.1 클라이언트와 서버

```text
사용자
→ DBeaver
→ PostgreSQL
→ 실행 결과
```

DBeaver는 DBMS가 아니라 PostgreSQL에 연결하는 클라이언트 도구임을 명확히 설명했다.

### 4.2 PostgreSQL 기본 계층

```text
PostgreSQL 서버
└── 데이터베이스
    └── 스키마
        └── 테이블
            ├── 행
            └── 열
```

Chapter 03의 DBeaver 탐색 화면과 직접 연결되도록 `public` 스키마를 소개했다.

### 4.3 데이터의 종류와 역할

- 정형·반정형·비정형 데이터
- 원본 데이터와 파생 데이터
- SQL 분석과 파생 결과의 관계

Chapter 01에서 소개한 원본·파생 데이터 개념을 이어받고 Chapter 14의 SQL 데이터 분석으로 연결했다.
