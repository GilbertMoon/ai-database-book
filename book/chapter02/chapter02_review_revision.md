## 1. 보완안 A: 핵심 용어 한눈에 보기 표

### 삽입 권장 위치

```text
Chapter 02 본문 15. 정리
정리 항목 앞 또는 뒤
```

### 삽입 문안

```markdown
### 핵심 용어 한눈에 보기

| 용어 | 한 줄 설명 | 예시 |
| --- | --- | --- |
| DBMS | 데이터베이스를 관리하는 소프트웨어 | PostgreSQL |
| 데이터베이스 | 실제 데이터가 저장되는 공간 | school_db |
| 테이블 | 데이터를 행과 열로 정리한 구조 | students |
| 행(Row) | 하나의 데이터 기록 | 김민지 학생 한 줄 |
| 열(Column) | 데이터 항목 | id, name, email |
| 기본키(PK) | 한 테이블 안에서 각 행을 구분하는 값 | students.id |
| 외래키(FK) | 다른 테이블의 기본키를 참조하는 값 | enrollments.student_id |
| 관계 | 테이블 사이의 연결 | students ↔ enrollments |
| CRUD | 생성, 조회, 수정, 삭제 | INSERT, SELECT, UPDATE, DELETE |
| 제약조건 | 잘못된 데이터를 막는 규칙 | NOT NULL, UNIQUE |
```

### 반영 이유

Chapter 02는 용어가 많은 장입니다. 초급 학습자는 본문을 읽은 뒤 여러 용어가 섞일 수 있으므로, 정리 부분에 한눈에 볼 수 있는 요약표를 추가하면 복습과 과제 수행에 도움이 됩니다.

## 2. 보완안 B: PK/FK 혼동 방지 문구

### 삽입 권장 위치

```text
Chapter 02 본문 5. 외래키(FK)
그림 2-4 아래 또는 외래키 SQL 예시 뒤
```

### 삽입 문안

```markdown
> 기본키와 외래키를 혼동하지 마세요.
>
> 기본키는 “내 테이블 안에서 각 행을 구분하는 값”입니다.
> 외래키는 “다른 테이블의 기본키를 참조해 관계를 만드는 값”입니다.
>
> 예를 들어 `students.id`는 students 테이블의 기본키이고,
> `enrollments.student_id`는 students 테이블의 `id`를 참조하는 외래키입니다.
```

### 반영 이유

초급자는 `id`, `student_id`, `course_id`를 모두 비슷한 숫자 컬럼으로 이해하기 쉽습니다. 기본키와 외래키의 차이를 한 번 더 짧게 강조하면 이후 ERD와 JOIN 학습으로 연결하기 좋습니다.
