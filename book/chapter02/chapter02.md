# Chapter 02. DBMS 기본 개념

> 상태: 초안

## 이 장에서 배울 내용

이 장에서는 데이터베이스를 이해하기 위해 꼭 알아야 하는 기본 용어를 학습합니다.

- 데이터베이스와 DBMS
- 테이블, 행, 열
- 기본키와 외래키
- 관계와 제약조건
- SQL과 CRUD

## 왜 이 내용을 배우는가

SQL을 작성하기 전에 데이터가 어떤 구조로 저장되는지 이해해야 합니다. 테이블, 기본키, 외래키를 이해하지 못하면 AI가 만든 설계가 맞는지 판단하기 어렵습니다.

## 핵심 개념

### 데이터베이스와 DBMS

데이터베이스는 데이터를 체계적으로 저장한 공간이고, DBMS는 그 데이터베이스를 관리하는 소프트웨어입니다.

### 테이블, 행, 열

테이블은 데이터를 행과 열로 정리한 구조입니다. 행은 하나의 데이터 기록이고, 열은 데이터의 항목입니다.

### 기본키(PK)

기본키는 각 행을 구분하는 고유한 값입니다.

### 외래키(FK)

외래키는 다른 테이블의 데이터를 참조하여 테이블 간 관계를 만드는 값입니다.

## 작은 예제

학생 테이블에는 학생 정보가 저장되고, 수강신청 테이블에는 어떤 학생이 어떤 강의를 신청했는지가 저장됩니다.

## AI 활용 실습

```text
학생, 강의, 수강신청 정보를 저장하는 데이터베이스 테이블을 설계해 주세요.
각 테이블의 기본키와 외래키를 표시해 주세요.
```

## 검토 질문

- 각 테이블에 기본키가 있는가?
- 수강신청 테이블에 학생과 강의를 연결하는 외래키가 있는가?
- 같은 정보가 여러 테이블에 중복 저장되어 있지는 않은가?

## 자주 하는 실수

- 이름이나 이메일을 기본키로 사용한다.
- 외래키 없이 텍스트 값으로 관계를 표현한다.
- 하나의 테이블에 너무 많은 정보를 몰아넣는다.

## 정리

DBMS 기본 개념에서 특히 중요한 것은 테이블, 행, 열, 기본키, 외래키, 관계입니다. 이 개념들은 이후 SQL, ERD, 정규화, 웹 CRUD 실습의 기초가 됩니다.
