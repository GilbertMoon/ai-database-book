# Chapter 02 독자 워크북

## 데이터와 DBMS의 기본 개념

> 이 워크북은 Chapter 02를 읽은 뒤 데이터베이스의 기본 구조와 용어를 직접 확인해 보는 선택형 보조 자료입니다. 복잡한 설계를 완성하기보다 이미 주어진 구조를 정확한 용어로 읽고 설명하는 데 집중합니다.

## 1. 워크북 활용 방법

Chapter 02에서는 다음 구조를 살펴보았습니다.

```text
사용자
→ DBeaver
→ PostgreSQL DBMS
→ 데이터베이스
→ 스키마
→ 테이블
→ 행과 열
```

이 워크북에서는 다음 질문에 답해 봅니다.

```text
DBeaver와 PostgreSQL은 어떤 역할을 하는가?
데이터베이스, 스키마와 테이블은 어떻게 포함되는가?
테이블의 한 행은 무엇을 나타내는가?
기본키와 외래키는 어떤 역할을 하는가?
원본 데이터와 파생 데이터는 어떻게 다른가?
AI가 만든 구조에서 어떤 기본 문제를 찾을 수 있는가?
```

## 7. 관계 유형 미리보기

다음 관계가 1:1, 1:N, N:M 중 무엇인지 판단해 보세요.

| 사례 | 관계 유형 | 판단 이유 |
| --- | --- | --- |
| 한 학생은 여러 질문을 작성할 수 있다 |  |  |
| 한 회원은 여러 주문을 할 수 있다 |  |  |
| 학생은 여러 강의를 신청하고 강의에도 여러 학생이 등록된다 |  |  |
| 한 사용자에게 하나의 상세 프로필만 존재한다 |  |  |
| 주문에는 여러 상품이 포함되고 상품도 여러 주문에 포함된다 |  |  |

지금은 관계의 유형만 구분합니다. 외래키 위치와 연결 테이블을 실제로 설계하는 활동은 Chapter 05에서 진행합니다.
