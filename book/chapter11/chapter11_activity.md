# Chapter 11 독자 워크북

## 데이터베이스를 안전하게 지키고 복구하는 방법

> 이 워크북은 `security_lab`을 기준으로 최소 권한, 비밀 정보 보호, 백업·복원 검증 결과를 기록하기 위한 자료입니다. 실제 운영 환경이 아니라 관리자 권한이 있는 테스트 환경과 별도 복원 DB에서 진행합니다.

---

## 1. 실습 파일과 순서

```text
01_security_lab_schema.sql
02_security_lab_seed.sql
03_role_permission_plan.sql
04_permission_checks.sql
05_restore_validation.sql
BACKUP_RESTORE_RUNBOOK.md
reset_security_lab.sql
```

권장 순서:

```text
01 → 02
→ 03에서 필요한 역할·권한 문장만 검토·선택 실행
→ 04 권한 확인
→ 터미널 백업·별도 DB 복원
→ 복원 DB에서 05 실행
→ RUNBOOK 기록
```
