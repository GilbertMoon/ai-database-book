# Chapter 11 Outline

## 제목
데이터베이스 보안과 백업

## 권장 분량
18~22페이지

## 이 장의 목적
SQL Injection, 권한 관리, 개인정보 보호, 백업과 복구의 기본 개념을 이해한다.

## 학습 목표
- SQL Injection이 왜 위험한지 설명할 수 있다.
- 안전한 SQL 작성 방식의 필요성을 이해할 수 있다.
- 계정과 권한 관리의 기본 원리를 설명할 수 있다.
- 백업과 복구가 필요한 이유를 설명할 수 있다.
- AI가 생성한 위험한 SQL 코드를 검토할 수 있다.

## 주요 개념
- SQL Injection
- 파라미터 바인딩
- 권한 관리
- 개인정보 보호
- 백업
- 복구
