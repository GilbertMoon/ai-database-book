CODE SQL 예제

실행되는 SQL과 올바른 SQL은 다릅니다

SELECT COUNT(*) AS student_count
FROM students AS s
INNER JOIN questions AS q
    ON q.student_id = s.id;

코드 전체를 보여 주기보다 이번 장에서 설명할 핵심 구문만 제시합니다.

질문이 없는 학생이 제외되는 문제와 학생이 질문 수만큼 반복되는 문제를 설명합니다.
