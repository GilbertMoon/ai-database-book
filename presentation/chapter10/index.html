Chapter 10 발표자료

10장은 대량 성능 실험 데이터를 바탕으로 실행 계획을 읽고, 같은 SQL의 인덱스 생성 전후를 비교해 적용 근거를 만드는 장입니다.

장표의 문서 아이콘 또는 S 키로 발표자 스크립트 창을 열 수 있습니다. 스크립트 창의 파란 단계 버튼을 누르면 실행 계획 노드, SQL 줄, 비교 표와 검산 기준이 같은 순서로 강조됩니다.

검증 기준: PostgreSQL 16. B-tree Skip Scan은 PostgreSQL 18에서 추가되었으므로 18 이상에서는 같은 SQL의 실행 계획이 달라질 수 있습니다. 실습 기록에는 서버 버전을 함께 남깁니다.
