# images/

이 폴더는 교재 본문에 삽입할 도식과 이미지를 관리합니다.

권장 구조:

```text
images/
├── chapter01/
├── chapter02/
├── chapter03/
└── ...
```

이미지 파일명 규칙:

```text
ch번호_주제_설명.png
```

예시:

```text
ch05_student_enrollment_erd.png
ch09_transaction_flow.png
ch14_rag_vector_search_flow.png
```

원칙:

```text
- 단순 장식용 이미지는 사용하지 않는다.
- 개념 이해, 구조 비교, 흐름 설명에 도움이 되는 도식을 우선한다.
- 본문에는 그림 번호와 캡션을 함께 작성한다.
```
