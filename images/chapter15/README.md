# Chapter 15 이미지/도식 설계

## Chapter 15. 최종 프로젝트 또는 최종 평가

이 문서는 Chapter 15 본문과 활동 자료에 삽입할 도식 후보를 정리한 이미지 설계 문서입니다.

Chapter 15는 전체 교재의 마무리 장으로, 지금까지 배운 데이터베이스 설계, SQL, AI 검토, NoSQL 선택, Vector DB/RAG 개념을 최종 프로젝트 또는 최종 평가로 종합하는 장입니다. 따라서 도식은 **최종 프로젝트 진행 흐름, 평가 방식 선택, 제출물 구조, DB 설계 검증 흐름, AI 활용 및 검토 루프, 평가 루브릭, 발표 구성, 최종 제출 체크리스트**를 직관적으로 이해할 수 있도록 구성합니다.

---

## 1. 도식 설계 원칙

```text
- 최종 프로젝트가 화면 구현보다 데이터베이스 설계와 검증 중심이라는 점을 강조한다.
- 요구사항 → ERD → DDL → 샘플 데이터 → 핵심 SQL → AI 검토 → 보고서/발표 흐름을 한눈에 보여 준다.
- 프로젝트형 평가와 시험형 평가를 선택 가능한 운영 방식으로 표현한다.
- 제출물 구조는 폴더 트리 형태로 명확히 보여 준다.
- AI 활용은 허용되지만 검토와 수정 기록이 필수임을 시각적으로 드러낸다.
- 평가 루브릭은 어떤 요소가 점수화되는지 빠르게 파악할 수 있게 한다.
- 최종 제출 체크리스트는 제출 전 누락 방지 용도로 사용할 수 있게 한다.
```

## 4. 도식 제작 후 점검 항목

```text
- 최종 프로젝트 진행 흐름이 요구사항부터 발표까지 자연스럽게 연결되는가?
- 프로젝트형 평가와 시험형 평가의 차이가 명확한가?
- 제출물 구조가 학생이 그대로 따라 할 수 있을 만큼 구체적인가?
- DB 설계 검증 흐름에 ERD, DDL, 샘플 데이터, 핵심 SQL이 포함되는가?
- AI 활용 및 검토 루프에서 AI 결과를 그대로 제출하지 않는다는 메시지가 드러나는가?
- 평가 루브릭이 주요 배점 항목을 균형 있게 보여 주는가?
- 발표 구성 도식이 5~7분 발표 흐름과 맞는가?
- 최종 제출 체크리스트가 누락 방지 용도로 사용할 수 있는가?
- 그림 번호와 캡션이 본문에 포함되었는가?
```
